# Challenge framework

Use for idea-grinder:

1. User and painful problem
2. Current workaround
3. Evidence of frequency and urgency
4. Alternatives and competition
5. Differentiation and distribution
6. Technical, security, and operational risks
7. Riskiest assumption
8. Smallest falsifiable experiment
9. Decision threshold
10. Verdict and confidence

Ask concise questions. Challenge the claim, not the person. A verdict can be “needs evidence”; uncertainty is a valid result.
