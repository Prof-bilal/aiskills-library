# Skill quality standard

A skill is an executable procedure for a recurring task, not a topic summary. Every skill must define when it activates, what context it needs, ordered actions, decision rules, verification, and a predictable output.

Review questions:
- Can an agent route a request from the description without guessing?
- Does it inspect before editing or recommending?
- Are high-impact decisions tied to evidence or an explicit escalation?
- Does verification test the actual outcome?
- Are assumptions, failures, and residual risks visible?

Keep conditional detail in references, scripts, templates, or playbooks. Use original wording and record public sources in `sources.json`; do not copy public skill text or proprietary assets wholesale.
