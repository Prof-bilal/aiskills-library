# Progressive disclosure

Portable Agent Skills have three useful loading levels:

1. Discovery loads only `name` and `description` for routing.
2. Activation loads the selected `SKILL.md` instructions.
3. Resources load only when the active workflow needs a reference, script, template, or example.

Keep `SKILL.md` focused on the decisions and actions required on every run. Put mode-specific detail in focused resources with shallow relative links.

Source: https://github.com/agentskills/agentskills/blob/main/docs/specification.mdx
